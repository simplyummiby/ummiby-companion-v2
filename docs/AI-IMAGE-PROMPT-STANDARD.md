Prompt structure:

Includes global image generation rules for Ummiby Companion.

## Visible Banner Output Requirement

Prompts must request a composition intended for the final shallow website banner. After generation, create and validate the exact visible crop before installing the artwork. Do not accept a banner based only on the uncropped generation canvas.
