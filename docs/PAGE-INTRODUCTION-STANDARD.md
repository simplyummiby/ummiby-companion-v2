# Page Introduction Standard

Version: 1.2  
Status: Active sitewide standard

Every major module home page follows this sequence:

1. Purpose-built cinematic banner
2. Module label, page title, and one-line purpose statement
3. Centered English epigraph
4. Module-colored signature divider
5. Functional page content

## Epigraph Standard

The epigraph is a quiet transition, not a card or content panel.

- Do not display a heading such as “Reflection.”
- Use English text only unless a page has a specific learning reason to include Arabic.
- Center the quotation and source.
- Use no background color, border, card, or shadow.
- Place the source beneath the quotation in smaller uppercase text.
- End with the shared geometric divider.
- The divider automatically uses the active module color.
- Preserve generous whitespace without delaying access to functional content.

The same structure is used sitewide. Only the quotation, source, and module color change.


## Extended Attribution Pattern — v3.4.2

When a quotation needs a brief transmission or explanation note, place it directly beneath the primary attribution in restrained sentence case. It remains part of the centered epigraph and must not become a separate card, heading, or content block.

A source may be represented by a small external-link icon immediately beside the attribution. Only the icon is clickable. The link must open in a new tab, include `rel="noopener noreferrer"`, and have an accessible label describing its action. Do not add “Read more” when the icon pattern is used.

Morning Duaas is the first collection page to adopt the official Page Introduction Standard. Its quotation, attribution, explanatory line, source icon, whitespace, and shared divider establish the approved collection-page implementation.
