# Ummiby Reader Framework

Version 3.8.4 establishes a reusable immersive-reader architecture.

## Principles

1. Content first.
2. Shared compact top bar and sticky bottom bar.
3. Context belongs in an optional companion panel.
4. Previous, primary action, and next remain grouped.
5. Secondary actions never interrupt linear reading flow.
6. Progress is not inferred from scrolling.
7. Saved place means the ayah where reading should resume.
8. Modules share structure while retaining their own color and contextual content.

## Reading Unit implementation

The Reading Unit reader uses Qur’an green, an About This Reading Unit panel, topic and study-resource sections, a reading-progress card, and deliberate Save My Place behavior. The same framework is intended for Classic Journey, Featured Readings, Duaa, Prayer, and other immersive experiences.
