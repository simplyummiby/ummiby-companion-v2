# Build Report — v3.29.3

## Featured Reading Consistency Start-Date Fix

- Consistency tracking now begins automatically on the earliest date marked Partial or Fully Read for each Featured Reading.
- Days before that first tracked reading are excluded from consistency calculations and no longer receive gray missed-reading markers.
- The denominator includes only reading windows that have closed.
  - Al-Mulk and As-Sajdah: through yesterday.
  - Al-Kahf: through the most recently completed Friday.
- Partial and Full readings both count toward consistency.
- The history summary label now reads Consistency Rate.
- Monthly insights use the same start-date and closed-window rules.
- A reading with one completed opportunity out of one eligible opportunity displays 100%.
