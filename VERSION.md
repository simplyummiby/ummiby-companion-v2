# Version

**Current version:** 3.4.8  
**Release name:** Duaa Collections Library Refresh  
**Release date:** 2026-07-26

## Scope

This UI/UX release redesigns the Duaa Collections page as a calm, compact library index that is faster to scan and ready to scale as more collections are added.

## Changes

- Replaced the wide collection-card grid with a centered alphabetical list.
- Added reusable `collection-index-item` rows with square artwork, title, description, and navigation caret.
- Generated square card thumbnails from the existing collection-page banners.
- Limited the index to a maximum width of 860px.
- Preserved the active Istikharah route using its existing illustration as a temporary thumbnail fallback.
- Added responsive row and thumbnail sizing for tablet and mobile.
- Preserved Duaa Home daily tracking cards, collection routes, epigraphs, banners, progress data, and reader functionality.
- Updated cache and release references to 3.4.8.
