# Ummiby Companion v3.4.12

## Duaa Collection Image Path Reliability

This release corrects the image URL base used by Duaa collection artwork. Assets now resolve relative to the project entry page, so they display when the app is served from a named project folder through VS Code Live Server or another static host subdirectory.

- Square banner crops appear in the Collections index.
- Landscape banner crops appear on applicable Duaa Home browse cards.
- Morning, Evening, and Before Sleep remain icon-based on Duaa Home.
- Istikharah retains its existing illustration until a dedicated banner is added.
- Refresh-safe hash routing remains in place.
