# Ummiby Companion v3.5.1

## Duaa Canonical Record Foundation

- Shared supplications now use a canonical duaa identity across collections.
- Memorizing a shared duaa in one collection marks it memorized everywhere it appears.
- Morning- and evening-specific virtues, repetition details, and presentation remain attached to their collection placement.
- The global memorization summary counts unique duaas rather than duplicate collection placements.
- Existing memorization progress is migrated safely: if either placement was marked memorized, the shared canonical record remains memorized.
