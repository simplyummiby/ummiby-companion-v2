- Courtyard artwork now visually continues beneath all Home content to the themed footer.
- Weather strip retains a time-of-day color derived from the active Home experience.

- Prayer strip now includes Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha. Sunrise is informational and cannot be marked as prayed.
- Daily Rhythm and Today’s Opportunities use the same outer left and right boundaries as the row above.
- Lower content was moved upward and compacted to support an everything-in-view desktop experience.
- Footer uses the active time-of-day accent rather than introducing an unrelated fixed color.
